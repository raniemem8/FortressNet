// the problem
Why combine monitoring with malware analysis?
Visibility without investigation leaves gaps, and investigation without visibility has nothing to start from.


Network visibility
Security teams need to see suspicious traffic, unusual connections and attack patterns.
Threat detection
FTP misuse, ARP poisoning and man-in-the-middle activity threaten confidentiality and integrity.
Malware investigation
Suspicious files must be examined in a controlled, isolated environment to understand their behavior.



// proposed solution
Two connected parts
Network defense and dynamic malware analysis, working as one pipeline.


Part 1: Network monitoring & detection
  • Build a virtual network in GNS3
  • Connect Kali Linux, VyOS, Windows 7 and Metasploitable
  • Deploy Security Onion
  • Monitor traffic with Suricata and Zeek
  • Review alerts and investigate suspicious activity


Part 2: Dynamic malware analysis
  • Create a separate, isolated sandbox
  • Automate safe analysis steps with Python
  • Run authorized samples only, inside the sandbox
  • Collect process, file-system and network behavior
  • Summarize behavior and indicators with an AI agent

// dynamic malware analysis
The isolated sandbox
A separate controlled environment for observing suspicious files.


Submit
Select a sample file.
Isolate
Use a disposable isolated VM.
Observe
Collect process, file and network behavior.
Automate
Python runs the steps and gathers results.
Explain
The AI agent summarizes behavior and indicators.


Safety boundary: harmless training samples or authorized samples only. Shared folders, clipboard and host integration are disabled, network access is restricted, and the VM snapshot is reverted after each run.

// evaluation
Expected results
Repeatable evidence for every claim.


  • Network visibility: capture and review relevant traffic and protocol activity.
  • Detection: document which FTP, MITM and ARP-poisoning activities produced useful alerts or logs.
  • Investigation: show how Suricata alerts and Zeek logs support analysis.
  • Sandbox safety: demonstrate isolation and snapshot recovery after a sample run.
  • Automation: measure how consistently Python collects results and produces a summary.
  • AI usefulness: evaluate whether summaries accurately reflect observed behavior.
